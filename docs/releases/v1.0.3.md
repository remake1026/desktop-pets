# line puppy v1.0.3 · Windows 10 / 11

本版本提供独立 Windows 安装包，内置运行环境，安装无需 Node.js，也无需联网下载依赖。

## 下载

在本页 Assets 中下载 **LineDog-1.0.3-Win10-11-Setup.exe**（约 180 MB）。这是桌面试用的“line puppy-1.0.3-Win10-11-安装包.exe”的同一文件，上传时仅调整文件名。

仅提供 Windows 10 / 11 版本，安装器自动选择 x86 或 x64 程序。`Source code` 文件为源码压缩包，不是安装包。

## 安装步骤

1. 如果小狗正在运行，先右键并点击“关闭萌宠”。
2. 双击安装包，选择仅为当前用户安装或为所有用户安装。
3. 点击“下一步”，选择安装目录，支持中文路径和其他磁盘。
4. 在“安装选项”页设置“创建桌面快捷方式”和“开机自动启动”。两项均默认勾选，可自行取消。
5. 点击“安装”，完成后勾选“运行line puppy”并点击“完成”。之后可通过桌面快捷方式或开始菜单启动。

## 日常使用

- 默认：小狗睡觉，安静陪伴。
- 鼠标悬停：小狗跳跃回应。
- 鼠标左键点击：播放爱心互动动画。
- 按住鼠标左键拖动：移动小狗位置。
- 鼠标移到小狗附近：右下角出现旋钮，拖动可调整大小。
- 鼠标右键：显示“关闭萌宠”按钮。
- 开机自启动：勾选后在登录 Windows 时启动；可重新运行安装包调整选项。
- 卸载：在 Windows 应用列表中卸载“line puppy”，或运行“卸载line puppy.exe”，对应的自启动项会随之清理。
