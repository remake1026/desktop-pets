# line puppy v1.1.0 · macOS

本版本提供 Apple Silicon 的 macOS 应用，可用 Homebrew 一键安装，也可下载 DMG 拖到「应用程序」。

## Homebrew 安装（推荐）

```bash
brew tap remake1026/desktop-pets https://github.com/remake1026/desktop-pets
brew install --cask line-dog
```

## 下载

- Homebrew 会自动下载 **LineDog-1.1.0-Mac-arm64.dmg**（约 113 MB）。
- 也可以在 Releases 的 Assets 中手动下载该 DMG。`Source code` 是源码压缩包，不是安装包。

仅提供 Apple Silicon（arm64）版本，需要 macOS Ventura 13 或更新系统。Intel Mac 请从源码自行构建。

## 安装步骤

1. 已安装 Homebrew 时，在终端执行上面的 `brew install --cask` 命令。
2. 打开「访达 → 应用程序」，双击 **line puppy**。
3. 如果系统提示无法验证开发者：按住 Control 再点击应用，选择「打开」，或执行 `xattr -cr "/Applications/line puppy.app"`。
4. 小狗会出现在桌面右下角附近，菜单栏右侧会出现图标。

## 日常使用

- 默认：小狗睡觉，安静陪伴。
- 鼠标悬停：小狗跳跃回应。
- 鼠标左键点击：播放爱心互动动画。
- 按住鼠标左键拖动：移动小狗位置。
- 鼠标移到小狗附近：右下角出现旋钮，拖动可调整大小。
- 鼠标右键：显示「关闭萌宠」按钮。
- 开机自启动：点击菜单栏图标，勾选或取消「登录时启动」。
- 卸载：`brew uninstall --cask line-dog`，或把应用程序里的「line puppy」移到废纸篓；若开启过登录启动，先在菜单栏取消勾选。

## 本版调整

- 增加 macOS 透明置顶窗口、点击穿透空白区域、菜单栏退出，不占用程序坞。
- 提供 Homebrew Cask，其他用户可以用 `brew tap remake1026/desktop-pets https://github.com/remake1026/desktop-pets` 后执行 `brew install --cask line-dog` 安装。
- 提供 `启动桌宠.command`，方便从源码在 Mac 上启动。
- Windows 安装包仍使用 v1.0.3。

## 验证范围

已在 Apple Silicon Mac 上验证应用启动、透明窗口、单实例、任务完成参数，以及 ad-hoc 签名后的本地打开。Homebrew 安装依赖 GitHub Release 中的 DMG。
